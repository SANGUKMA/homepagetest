## 1. 배경 & 문제 정의

온라인 대학(AI융합 학위과정 맥락)은 현재 잠재 지원자가 **과정 정보를 확인하고 문의할 공식 창구가 없다.** 문의가 개인 채널로 흩어지면 응대 누락·전환 손실이 발생한다.

Phase 1은 이 문제를 좁게 해결한다:

- 대학과 학위과정을 **신뢰감 있게 소개**하고,
- 관심자가 **한 곳에서 입학·과정 문의를 남기며**,
- 운영자가 **문의를 빠짐없이 열람·응대**하게 한다.

LMS(수강·강의·평가)는 2단계로 분리한다. `CLAUDE.md` 규칙에 따라 범위 확정 전까지 LMS 도메인은 이 문서에서 다루지 않는다.

## 4. 범위 (Scope)

### 4.1 In Scope (Phase 1)

- 대학/기관 소개, 학위과정 소개, 입학 안내 공개 페이지
- 입학·과정 문의 폼 접수 + 개인정보 동의
- 관리자 로그인 및 문의 열람·상태 관리
- 반응형(모바일 우선), 한국어 카피, 기본 SEO

### 4.2 Out of Scope (Phase 2 이후)

- 수강신청·강의 콘텐츠·과제·평가·성적 (LMS)
- 결제·정산, 수강생 마이페이지
- 학생 회원가입/역할 기반 권한(관리자 외)
- 실시간 상담(챗), 다국어 실번역(구조만 대비)

## 6. 기능 요구사항 (Functional Requirements)

우선순위: **M**ust / **S**hould / **C**ould / **W**on't (MoSCoW)

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| FR-1 | 기관 소개 | 대학·파트너십·비전 소개 페이지 | M |
| FR-2 | 학위과정 소개 | 과정 목록 + 과정 상세(커리큘럼·학위·기간·대상) | M |
| FR-3 | 입학 안내 | 모집요강·전형 절차·일정·장학 안내 | M |
| FR-4 | **문의 접수** | 입학·과정 문의 폼 제출·저장 | M |
| FR-5 | 접수 완료 안내 | 제출 후 완료 화면 노출 | M |
| FR-6 | 개인정보 동의 | 수집·이용 동의 체크(미동의 시 제출 불가) | M |
| FR-7 | 관리자 로그인 | Supabase Auth 인증 | M |

| FR-12 | 스팸 방지 | 허니팟 + Cloudflare Turnstile | S |

| FR-14 | 문자열 분리 | 노출 카피 1곳 관리(다국어 대비) | S |
| FR-15 | 이용약관 | 이용약관 고지 페이지 | S |

> M0 확정으로 FR-10·FR-12·FR-14·FR-15가 Phase 1 범위에 포함되었다. 상세는 §12 참조.

### 6.1 핵심 기능 인수 조건 — FR-4 문의 접수

- **Given** 방문자가 문의 폼에서 이름·이메일·문의유형·내용·개인정보 동의를 입력하고
- **When** 제출하면
- **Then** 클라이언트 검증(zod) 통과 → 서버 재검증(zod) 통과 시 `inquiries`에 저장되고 `/inquiry/complete`로 이동한다.
- 개인정보 동의를 체크하지 않으면 제출할 수 없다.
- 검증 실패 시 **한국어 에러 메시지**를 보여주고 입력값을 보존한다.
- 서버는 클라이언트 검증을 신뢰하지 않고 항상 재검증한다. *(CLAUDE.md §5)*
- 저장 실패 시 데이터 유실 없이 재시도를 안내한다.

## 11. 의존성 & 가정

- **가정** — KACI×GCU AI융합 학위과정 맥락. **미확정** — 확정 전까지 일반 카피로 두고, 확정 시 문자열만 교체(구조 불변).
- **확정** — 관리자는 소수(단일 조직). 인증자=관리자. 역할 기반 권한은 Phase 2.
- **승인 완료** — `zod`, `@supabase/ssr` (M1 착수 시 설치).
- **승인 대기** — 이메일 발송 수단(Resend 등), Turnstile 연동 방식. M2 착수 시 별도 제안. *(CLAUDE.md §7)*
- **의존성** — 과정·입학 콘텐츠(카피·일정·요강) 원문 제공 필요.
- **의존성** — 개인정보처리방침·이용약관 원문, FAQ 문항 제공 필요.
- **인프라** — Supabase 프로젝트, Vercel 프로젝트, 이메일 발신 도메인, Cloudflare Turnstile 키.
